## 特性

- Material Design 3 主题（亮色/暗色）
- 零依赖
- 响应式设计
- SEO 优化
- 全文搜索
- 评论系统（可选）
- Mermaid 图表
- 目录
- RSS 订阅

## 快速开始

1. 克隆仓库
2. 编辑 `site.config.json`
3. 添加头像到 `static/`
4. 在 `content/blog/` 创建文章
5. 构建：`node build.js`
6. 部署到 Vercel 或任何静态托管
