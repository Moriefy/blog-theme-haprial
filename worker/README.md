# Comments Worker

> English | **[中文文档](README_CN.md)**

Cloudflare Worker backend for the Haprial blog comments system.

## Features

- Comment CRUD operations
- Like system
- Admin dashboard
- Rate limiting
- Spam protection
- Email notifications (via Resend)
